# Third-party fonts

The mod bundles 16 font files from 15 font families. These fonts are **third-party work**, not AI-generated project code. Each font remains licensed under **SIL Open Font License 1.1**. Original copyright notices and complete license texts are retained in `assets/fonts/`.

The MIT license for this project's code does not replace the font licenses. See the [official SIL OFL text](https://openfontlicense.org/open-font-license-official-text/) for its terms, including redistribution, reserved font names, and selling font software by itself.

Shantell Sans and Caveat are static weight-700 derivatives. Nunito ExtraBold, Rubik SemiBold, and Comfortaa Bold are static weight-800, weight-600, and weight-700 derivatives respectively. These five derivatives use renamed internal font families prefixed with `Gardendless`; glyphs and original copyright/license notices are retained. Display names identify their upstream families; inspect each original notice for authorship and font-specific terms.

`metrics.json` contains normalized glyph width data for text fitting. `examples/fonts.png` shows font samples and is not a game screenshot. The repository does not redistribute the game engine, extracted game modules, game artwork, sound files, translation-pack content, or player saves. Runtime names and asset references in the mod refer to the user's installed game.
