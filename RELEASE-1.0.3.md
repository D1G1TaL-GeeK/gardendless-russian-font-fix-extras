# Russian Font Display Fix & Extras 1.0.3

Номер версии сохранён. Собраны последние исправления шрифтов, интерфейса, автоподбора и общего TXT-журнала игры.

**Я частично восстановил режим вазобоя:** отдельный набор из **12 обычных и 12 бесконечных уровней** в 12 мирах. Случайные растения и зомби, солнце/подкормка в вазах, взрывы, Фонарь и смена раундов. Исправлены остатки растений/мумий и исчезновение снарядов после зачистки. Sky City исключён.

## Что установить

- **Russian_Font_Display_Fix_Extras_1.0.3.zip** — мод шрифтов и интерфейса. **F9 → Mods → Import ZIP → включить → применить → полностью перезапустить игру.** Для русского текста отдельно нужен русификатор. JavaScript-моды включаются в **Experimental → JS Modding**.
- **Vasebreaker_24_Levels_And_Rules.zip** — сначала **распаковать**. Вложенный **Vase_Chaos_Rules.zip** установить через **Mods → Import ZIP**, включить правила и полностью перезапустить игру. Затем в настройках самой игры открыть **Play Local Level** и выбрать **JSON из levels/**. Внешний архив с уровнями не импортируется как мод.
- **SHA256SUMS.txt** — контрольные суммы двух ZIP.

Для вазобоя: **Gardendless 0.15.0 и GP-Next 1.5.5**. Номер правил сохранён — **1.2.0**. Для уже добавленных карт достаточно обновить правила; повторный импорт JSON для исправлений не нужен.
