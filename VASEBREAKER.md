# Вазобой / Vasebreaker — установка и правила

Я частично восстановил режим вазобоя в PvZ2 Gardendless. В наборе **24 карты: 12 обычных и 12 бесконечных**, по одной паре для каждого мира. Sky City исключён. Это самостоятельные пользовательские уровни; режимы и баланс не полностью повторяют первую Plants vs. Zombies.

## Установка

1. Установите **Gardendless 0.15.0** и **GP-Next 1.5.5**. Для русского текста отдельно включите русификатор; мод шрифтов из этого релиза улучшает его отображение.
2. Скачайте **[Vasebreaker_24_Levels_And_Rules.zip](https://github.com/D1G1TaL-GeeK/gardendless-russian-font-fix-extras/releases/download/v1.0.3/Vasebreaker_24_Levels_And_Rules.zip)** и распакуйте его в обычную папку.
3. В **F9 → Experimental → JS Modding** включите JavaScript-моды. Через **Mods → Import ZIP** импортируйте именно вложенный **Vase_Chaos_Rules.zip**, а не внешний архив с уровнями. Включите «Правила вазобоя», подтвердите доверие при запросе и примените выбор.
4. Полностью закройте и заново запустите игру. Оставляйте включённой одну копию правил.
5. В настройках самой игры откройте **Play Local Level** («Играть в локальный уровень») и выберите нужный **JSON из levels/**. Обычные уровни идут первыми; бесконечные имеют **endless** в имени. Переходы между раундами бесконечного уровня происходят автоматически.

[Официальная инструкция GP-Next](https://pvzge.com/en/guide/mod/gp-next) · [Официальный FAQ об открытии JSON уровней](https://pvzge.com/en/guide/FAQ#how-do-i-import-a-custom-level)

## Как играть

- Разбейте вазы, подберите выпавшие растения и победите зомби. Начинаете с **0 солнца**; солнце и подкормка могут находиться в вазах. Ими можно воспользоваться для защиты и покупки растений из доступных карточек.
- При повторе меняются растения, зомби и их места. В каждом раунде есть минимум пять разных растений с постоянной атакой — для пяти стандартных рядов.
- Гаргантюа соответствуют миру и находятся только в особых фиолетовых вазах. Иногда выпадает Фонарь, показывающий содержимое соседних ваз.
- Взрывающиеся растения разбивают вазы в области взрыва. Выпавшие карточки не исчезают быстрее из-за ускорения игры. Повторный клик по выбранной карточке позволяет посадить её в клетку, где она выпала.
- Через **10 секунд бездействия** открывается случайная ваза; на отдельных картах — две. Последние **5 секунд** выбранные вазы мерцают. Ввод игрока и действия сбрасывают таймер и мерцание; автоматические атаки растений его не сбрасывают. На паузе отсчёт останавливается.
- Бесконечный режим: **2 → 3 → 4 → 5** правых столбцов с вазами, затем всегда пять. Поле очищается до нового раунда. Слева остаётся место для посадки; стандартных рядов всегда пять.
- Автоподбор листиков подкормки управляется только отдельной галочкой мода шрифтов; «прочий дроп» их не собирает.

## Исправления и обновление

В сборку включены запрет могил поверх ваз в Египте, восстановление вида вазы после съедания Фонаря, очистка копий Спорогриба, защита от запоздавшей мумии Гаргантюа и безопасное повторное использование снарядов после смены раунда.

Номер мода правил сохранён: **1.2.0**; основной релиз — **1.0.3**. Если карты этого набора уже добавлены, для исправлений достаточно обновить вложенный ZIP правил и полностью перезапустить игру. Если текст старых целей отличается, откройте обновлённый JSON из архива.

Проверки включают структуры всех 24 карт, случайные составы, переходы бесконечных раундов и отдельные проверки на настоящих модулях игры/Cocos. Полного ручного прохождения всех режимов не было.

## English installation

Download and **unzip the outer Vasebreaker pack**. Import its **Vase_Chaos_Rules.zip** under **F9 → Mods → Import ZIP**, enable JS Modding and the rules, apply and fully restart. In the game's settings, choose **Play Local Level** and open a JSON from **levels/**. Use **GP-Next 1.5.5**. A Russian translation pack is separate; the font mod does not contain a complete translation. Existing maps only need the updated rules ZIP for runtime fixes.
