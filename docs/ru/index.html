Русские шрифты для PvZ2 Gardendless

Russian Font Display Fix & Extras — бесплатный JavaScript-мод GP-Next для фанатской игры Plants vs. Zombies 2: Gardendless. Он улучшает отображение кириллицы, отступы интерфейса и диалоги, а также добавляет необязательные настройки игры.

Скачать мод 1.0.3 (ZIP)Как установитьИсходный код на GitHub

Для русского текста игры нужен отдельный включённый русификатор. Этот мод исправляет шрифты и интерфейс, но не содержит полного перевода.

Возможности

Читаемая кириллица

Выберите одно из 15 семейств для каждого из пяти исходных шрифтов. Предпросмотр интерфейса, реплик Дейва, Зомбосса, Пенни и предупреждений рисует игровой движок. Общий размер текста настраивается от 50% до 80%.

Отступы интерфейса и диалогов

Улучшены подгонка текста, переносы подсказок, отступы альманаха, поля игрового интерфейса и кнопки магазина. У Пенни базовый размер реплик такой же, как у Дейва. Пиньята скрывается на время подсказок при переходах между меню.

Дополнительные настройки игры

Отдельные галочки автоподбора прочего дропа, солнца и листиков подкормки; множитель ускорения от 1× до 10× с шагом 0,1, изменяемый во время игры; режим читов и настройка стоимости усилений в монетах.

Группа автоподбора и ручная настройка ускорения по умолчанию выключены. Отключение группы автоподбора снимает все вложенные галочки. Выбор режима читов сам по себе не включает игровые читы.

Вопросы

Это русификатор PvZ2 Gardendless?

Пакет исправляет русские шрифты, кириллицу и размещение текста. Для перевода игры установите отдельный русификатор. Мод не привязан обязательной зависимостью к одному ID пакета перевода.

Какие версии игры и GP-Next проверены?

Gardendless 0.15.0, Cocos 3.8.4 и GP-Next 1.5.4 / 1.5.5. Манифест допускает GP-Next ≥1.5.4 и <2.0.0, но другие версии не проверены.

Какой архив нужно скачивать?

Для установки нужен Russian_Font_Display_Fix_Extras_1.0.3.zip. Архив _Source.zip и автоматические архивы исходного кода GitHub предназначены для разработки. Пройдите установку через GP-Next и полностью перезапустите игру.

Почему панель GP-Next остаётся английской?

Язык запуска игры в моде настраивается отдельно от языка панели GP-Next. Загрузка начинается на английском, пока регистрируется русский перевод. Для русских игровых текстов нужен отдельный русификатор.
