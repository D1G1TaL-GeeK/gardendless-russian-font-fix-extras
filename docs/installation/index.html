Install the Gardendless Russian Font Fix with GP-Next

Installation and update instructions for Russian Font Display Fix & Extras 1.0.3. Import the ready-to-use ZIP through the game; no Python, Node.js or compiler is needed.

Download mod 1.0.3 (ZIP)Installation guideSource on GitHub

Before you install

  • Checked with Gardendless 0.15.0 / Cocos 3.8.4 and GP-Next 1.5.4 / 1.5.5. Other versions have not been verified.
  • Russian text requires a separate enabled Russian translation pack.
  • Download the installable ZIP, not the _Source.zip archive. You can check its SHA-256 against SHA256SUMS.txt on the release page.

Install the mod in GP-Next

  1. Download Russian_Font_Display_Fix_Extras_1.0.3.zip from the GitHub release.
  2. Return to the main menu. Open F9 → Experimental → JS Modding, enable it and review/confirm the GP-Next script notice.
  3. Open Mods → Import ZIP and select the archive directly. Check its name and version. Install and enable your Russian translation pack separately.
  4. Enable Russian Font Display Fix & Extras. Review the package and confirm script trust, including renewed trust after an update if requested.
  5. Save/apply the mod selection, fully close the game and launch it again. Restarting only a level is insufficient.
  6. Open the mod details in F9 → Mods, or use State and controls → Русский шрифт и размеры. The mod controls are labelled in Russian; GP-Next's panel language is independent.

Update, reset or remove

Import the new ZIP with the same mod ID. Valid saved font, size, language, price, collection and speed choices remain. Avoid keeping two versions enabled. To apply the recommended five-font defaults to an existing installation, press Вернуть рекомендуемое оформление.

To disable or remove the mod, use the mod manager, save/apply and fully restart. The latest release is 1.0.3; version 1.0.2 was withdrawn.

INSTALL_CORRUPT or STARTUP_FAILED before the engine loads

GP-Next checks installed package bytes against their recorded digest. Direct changes inside gp-next/installed/ can cause INSTALL_CORRUPT and STARTUP_FAILED at beforeEngineImport, even if modIssues is empty. This mod cannot run a repair before its own script loads.

Preserve saves and backups. Use the recovery screen's mod-manager/import action to reimport an unchanged package. If the manager cannot open, follow the official GP-Next recovery guide, then reimport through the manager. Other startup failures need their full error details; these codes alone do not prove one particular cause.

Fonts and optional settings

First-install text size is 68%. The recommended fonts are Shantell Sans Bold, Comfortaa Bold, Caveat Bold, Comfortaa Bold and Ruslan Display for the five original font slots. See the native font roles and preview.

Auto-collection, manual fast-forward and the planning copy fix are off by default. Other drops exclude sun and plant-food leaves; those use separate switches. The fast-forward slider accepts 1–10× in steps of 0.1, with a decimal point or comma in the input. Selecting “Allow cheats” only permits the native cheat switch; enable cheats separately if wanted.
