Russian Font Fix for PvZ2 Gardendless

Russian Font Display Fix & Extras is a free GP-Next JavaScript mod for the Plants vs. Zombies 2: Gardendless fan game. It improves Cyrillic text, interface spacing and dialogue, with optional gameplay settings.

Download mod 1.0.3 (ZIP)Installation guideSource on GitHub

Russian game text requires a separate enabled Russian translation pack. This font and interface mod does not include a complete translation.

Features

Readable Cyrillic text

Choose from 15 bundled font families for five original font slots. Preview interface text, Dave, Zomboss, Penny and warnings in the game engine. Adjust the overall text size from 50% to 80%.

Interface and dialogue spacing

Improve text fitting, hint wrapping, Almanac spacing, HUD margins and shop controls. Penny uses Dave's native dialogue base size. Piñata Party is hidden while menu-transition tips are visible.

Optional gameplay settings

Configure separate auto-collection switches for other drops, sun and plant-food leaves; set a live fast-forward multiplier from 1× to 10× in steps of 0.1; choose cheat handling and edit power-up coin prices.

The auto-collection group and custom fast-forward are off by default. Turning off the collection group clears all its nested switches. Selecting a cheat mode does not automatically activate the game's cheats.

Questions

Is this a Gardendless Russian translation or russifier?

This package fixes Russian/Cyrillic fonts and layout. Install a separate Russian translation pack to translate the game text. The mod is not tied to one specific translation-pack ID.

Which game and GP-Next versions are checked?

Gardendless 0.15.0 with Cocos 3.8.4 and GP-Next 1.5.4 / 1.5.5. The manifest accepts GP-Next ≥1.5.4 and <2.0.0, but other versions have not been verified.

Which ZIP should I install?

Use Russian_Font_Display_Fix_Extras_1.0.3.zip. The _Source.zip and GitHub's automatic source archives are for development. Follow the GP-Next installation guide and fully restart the game.

Why can GP-Next's panel stay English?

The mod's startup game-language setting is separate from the GP-Next panel language. Loading starts in English while the Russian translation registers; Russian game text needs the separate translation pack.
